# 🛡️ TruthShield

### AI-Powered Fake News Detection

TruthShield is a web application that helps users analyze news content using **AI-powered analysis** to identify potentially misleading information.

## 🚀 Live Demo

### **[🌐 Try TruthShield Live](https://truthshield-tfr3.onrender.com)**

## ✨ Features

* 📰 Analyze news text
* 🔗 Analyze content from URLs
* 🖼️ Upload images for analysis
* 🤖 AI-powered content analysis
* 📊 Clear analysis results
* 📱 Responsive modern UI

## 🛠️ Tech Stack

* **Frontend:** React, Vite, Tailwind CSS
* **Backend:** Node.js, Express
* **AI:** Google Gemini API
* **Icons:** Lucide React
* **Deployment:** Render

## ⚙️ Run Locally

```bash
git clone https://github.com/Arjunsanthoshen/TruthShield.git
cd TruthShield

npm install
npm run dev
```

Create a `.env` file and add the required API key:

```env
GEMINI_API_KEY=your_api_key
```

The development server runs on:

```text
http://localhost:5173
```

## 📌 Disclaimer

TruthShield is an AI-assisted analysis tool. Its results should not be treated as definitive proof that information is true or false. Always verify important claims using reliable sources.
